## Design Context

### Users
Solo creator / developer using kiteracer as a personal generative art lab. Context is a darkened screen, full attention on the canvas. Controls are accessed deliberately, not constantly — the UI should get out of the way and let the animation breathe.

### Brand Personality
Precise. Quiet. Alive. The tool has opinions but doesn't shout them.

### Aesthetic Direction
Refined minimal — the panel should feel like a professional instrument, not a settings drawer. Influenced by Linear's sidebar: slides in on demand, overlays without disrupting, can be pinned. Dark-first (the canvas is black), with the panel almost disappearing into it. No rounded corners, no shadows on the panel itself, no decorative elements. Every pixel earns its place.

Anti-references: glassmorphism showcases, neon-accent dark UIs, settings panels that look like mobile apps.

### Design Principles
1. **The canvas is the product** — UI is infrastructure. Default state should be no visible panel.
2. **Reveal on intent** — hover-triggered slide-in; pin to lock open. Never intrudes.
3. **Monochrome discipline** — all UI colors are tints/shades of the canvas palette. No independent accent colors.
4. **Density without clutter** — compact controls, quiet labels, grouped by function not alphabet.
5. **Same material** — panel uses the same font (Geist Mono), same color variables, same aesthetic language as the canvas cells.
